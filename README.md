# Verified Research Engine

Verified Research Engine (VRE) writes sourced research briefs. You give it a topic; it splits the topic into questions, researches each one, and writes a brief in which every factual sentence cites the passage it came from.

> **Status: in development. Phase 1 of 12 is complete.**
> Today a topic goes in and a cited brief comes out, from public web sources. Claim checking, your own PDF documents, human approval, and the API arrive in later phases (see [Roadmap](#roadmap)). Citations in Phase 1 briefs are not yet verified.

When finished, VRE will differ from a general AI report writer in three ways:

- **It reads your files as well as the web**, and reports where the two disagree.
- **It checks its own citations.** A claim whose source does not support it is rewritten, removed, or labelled unverified.
- **Nothing is final until a person approves it**, and every run records what it did and what it used.

## How it works (Phase 1)

```text
topic
  |
  v
planner      one model call: splits the topic into up to 6 sub-questions (Q1..Q6)
  |
  v
researcher   one web search per sub-question; the top 3 results become findings (Q1-F1..)
  |
  v
writer       one outline call, then one call per section, each given only that
  |          section's findings; every citation is checked against them in code
  v
brief        Markdown, with a list of the sources it actually cites
```

The graph is a LangGraph `StateGraph`. One run is one trace in LangSmith, with every model call, its prompt version, and its inputs and outputs.

### Principles the code follows

| Principle | Where |
| --- | --- |
| Every model decision returns a validated Pydantic object, never free text | `graph/schemas.py` |
| Every model call goes through one gateway: shared rate limit, retries, trace tags | `graph/llm.py` |
| Ids (`Q2`, `Q2-F1`) are assigned by code, never by the model | `graph/nodes/planner.py`, `graph/nodes/researcher.py` |
| Rules that must hold are checked in code, not only asked for in a prompt | the checks in each node |
| A section's prompt holds only that section's evidence | `graph/nodes/writer.py` |
| The whole graph is tested end to end with a scripted model and a fake search, with no network | `tests/` |

## Run it

You need Python 3.12 (installed by `uv`), [`uv`](https://docs.astral.sh/uv/), and free API keys for Mistral, Tavily, and LangSmith. Commands are for Windows PowerShell.

```powershell
git clone https://github.com/HuMzAHCodes/verified-research-engine.git
cd verified-research-engine
uv sync
uv run nbstripout --install
Copy-Item .env.example .env
notepad .env
```

Fill in the three keys in `.env`. The file is ignored by git; never commit it.

**Tests that need no keys and no network** (the same ones CI runs on every push):

```powershell
uv run pytest -m "not live"
```

**One real brief:** open `notebooks/phase_01.ipynb` in VS Code, choose the project's `.venv` as the kernel, and run all cells. A run takes about a minute, makes up to 8 model calls and 6 searches, prints the LangSmith link to its trace, and writes `notebooks/phase_01_brief.md`.

**Live checks** against the real APIs (they spend free-tier quota):

```powershell
uv run pytest -m live -s
```

## Keeping secrets out of this repository

- API keys are read only from `.env`, in one place (`settings.py`), and are never printed.
- `nbstripout` removes notebook outputs at commit time, so nothing a cell printed is committed.
- A test (`tests/unit/test_no_secrets.py`) runs in CI and fails if any tracked file contains a key-shaped string, an actual key value, a tracked `.env`, or a notebook with outputs.

## Project layout

```text
settings.py              the only reader of environment variables
graph/
  llm.py                 model gateway
  schemas.py             what each model call must return
  state.py               what a run keeps between steps
  supervisor.py          builds the graph
  report.py              renders a brief as Markdown
  prompts/               prompt text, one module per prompt group, each with a version
  nodes/                 planner, researcher (temporary, Phase 1), writer
tests/
  unit/                  scripted tests: no keys, no network
  live/                  real API checks, run on request
notebooks/
  phase_01.ipynb         one real run
  phase_01_brief.md      the brief it wrote
```
